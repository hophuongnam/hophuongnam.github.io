Nôm Khải

Font Nôm phát triển dần từ nét Khải. Bản đã duyệt: 0.5.1. Chữ chưa thiết kế dùng Nôm Na Tống dự phòng.

Một link dùng chung

<link rel="stylesheet" href="https://hophuongnam.github.io/fonts/nom-khai/nom-khai.css">

Dùng class="nom-khai" hoặc:

font-family: "Nom Khai", serif;
font-weight: 400;

剏𦉱𣇞𠦺, 𥪝根房𥊚蕞, 𨕭隻𪲝𡘯㛪僾, 张蚖圊眣𪹚省, 揞𥙩頭, 𢯐𠊛如𡥵𩵽.

理凡𢪲𥗜𨢇, 𥆾𡌽文武伯關𦤾𪢣壽帙謹大凊; 唒㐌於歲𠸗𠉞儉, 𪝳吻不覺得意.

Link CSS giữ nguyên khi thêm chữ. Chỉ bản đã duyệt được phát hành; tải lại trang để nhận bản mới sau thời gian cache khoảng 10 phút. File tải về máy cần cập nhật thủ công.
